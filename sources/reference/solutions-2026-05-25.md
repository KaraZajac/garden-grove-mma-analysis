# Solutions brainstorm

Conventional + unconventional mitigation options for the Garden Grove MMA tank, ranked. Each option assessed for mechanism, feasibility, risk, and expected efficacy on model parameters.

## Top 5 prioritized actions

1. **Chilled-water tanker swap (B3)** — switch the external spray from ~70 °F hydrant water to 33–40 °F glycol-water from breweries (Anheuser-Busch Van Nuys), dairies, or ice-rink chillers. 24 h deploy via CalOES mutual aid. Improves UA·ΔT by 50–70%, no shell-shock risk, leverages existing posture. **Single highest benefit-to-risk action.**

2. **Submersible cooling coil via non-gummed port (E3)** — only intervention that attacks bulk T directly. Lower a chilled-glycol coil through any accessible nozzle / instrument boss / manway. The polymer plug per Picazo blocks the main valve, but auxiliary penetrations may still be usable. Engineering walk-down to identify a port should begin immediately. 48–72 h if a port exists.

3. **Robotic remote relief drilling (C1)** — bomb-squad EOD robots (LAPD, OCSD, FBI LA) with Be-Cu bit + N₂/fog curtain. Operationalizes Covey's "preferred outcome" (controlled spill) rather than waiting for the tank to choose. Pair with D2 (mobile flare) + D3 (berm hardening). 24–48 h.

4. **Phenothiazine inhibitor cocktail drone-delivered through the crack (A3+A1)** — phenothiazine specifically (NOT MEHQ — bulk is almost certainly O₂-depleted, MEHQ requires dissolved O₂). Low cost adjunct. 24–48 h to fabricate drone payload.

5. **Expand evacuation to 1.5 mi mandatory + pre-stage MCI/burn/decon (F2+F3)** — pure consequence reduction for the ~7% BLEVE tail. Half-mile debris worst case per Picazo + 15% refusal rate makes this important.

## Promising — worth trying

- **B1 — CO₂ snow curtain** (not LCO₂ jet) — 2-4× local UA on shell + blanket excludes O₂ around vapor leaks. Manage thermal-shock gradient.
- **B4 — Ice slurry / pumpable ice** — 2-3× cooling capacity of chilled water. 48-72 h.
- **B5 — Misting curtains** — free upside, near-noise level.
- **D3 — Berm augmentation** — pure consequence-reduction.
- **E1 — Spot / EOD robot platform** — enables otherwise-impossible interventions.
- **E4 — Vapor extraction via vacuum pump** — directly attacks P_h; combines with C1.
- **F4 — Federal asset deployment** — request 9th Civil Support Team (chem/bio), EPA Region 9 ERT, DOE NEST (radiological-trained robotics translate well).

## Last resort

- **A2 — Hot-tap drilling** — drilling vibration on stressed shell could propagate the crack. Only if instrumentation shows clear runaway acceleration.
- **C2 — Crack augmentation via waterjet** — C1 dominates.

## DO NOT ATTEMPT

- **A4 — O₂ / dry-air bubbling through crack** — pushes headspace through 1.7-8.2% flammable range. Static discharge ignition risk.
- **A5 — Sulfide compounds** — wrong chemistry; adds H₂S hazard.
- **B2 — Liquid nitrogen surface chilling** — thermal-shock brittle fracture risk on stressed carbon steel + crack. Textbook BLEVE trigger.
- **C3 — Foam injection on crack** — seals the passive vent; raises P_h. Counterproductive.
- **C4 — N₂ headspace blanketing** — DEFEATS MEHQ by stripping dissolved O₂. This is exactly the Synthron / Rohm-Haas failure mode.
- **D1 — Deliberate BLEVE** — doesn't reduce blast radius; political/legal consequences extreme; not warranted while 93% model holds.
- **E2 — Thermal lance** — 4,000 °F = guaranteed MMA vapor ignition.

## Key chemistry insights

- **Phenothiazine, not MEHQ** is the right inhibitor here. MEHQ requires dissolved O₂ which is gone from the bulk.
- **Carbon-steel + MMA promotes polymerization** (per SDS §7) — already an aggravating factor.
- **The "stuck valve" is a polymer plug**, not a mechanical failure — gummed by self-polymerization. Any other port likely has the same risk.
- **MMA boiling point 101 °C / 214 °F** is the hard physical BLEVE threshold (Picazo).
- **Bulk-temp interventions dominate shell-only interventions** — carbon-steel + slow internal convection means shell-cooling barely couples to bulk-T.

## Bottom line

OCFA's posture is rational ("contain and wait") but missing the bulk-T attack vectors. The model's 93% holds is conditional on the current operational posture continuing to work. Any of #1, #2, or #3 above would meaningfully shift the posterior toward survival.
